# Docs Index

Folder ini berisi dokumentasi operasional dan teknis untuk project ini.

## Mulai Dari Sini

Kalau tujuan Anda adalah menjalankan export di local:

- `HOW_TO_RUN.md`

Kalau tujuan Anda adalah menyiapkan bot Telegram:

- `HOW_TO_CREATE_BOT_TELEGRAM.md`
- `HOW_TO_RUN_BOT_TELEGRAM.md`

Kalau tujuan Anda adalah deploy bot ke Railway:

- `HOW_TO_DEPLOY_BOT_TELEGRAM_RAILWAY.md`

Kalau tujuan Anda adalah memahami kontrak integrasi bot ke flow custom:

- `HOW_TO_INTEGRATE_BOT_TELEGRAM.md`

## Ringkas Fokus Dokumen

- `HOW_TO_RUN.md`: setup local, env, dan command untuk menjalankan project
- `HOW_TO_CREATE_BOT_TELEGRAM.md`: membuat bot lewat BotFather dan mengambil token
- `HOW_TO_RUN_BOT_TELEGRAM.md`: arsitektur dan operasional service bot webhook
- `HOW_TO_DEPLOY_BOT_TELEGRAM_RAILWAY.md`: deploy bot ke Railway
- `HOW_TO_INTEGRATE_BOT_TELEGRAM.md`: payload runtime, hasil run, dan kontrak integrasi ke flow `src_custom/`
